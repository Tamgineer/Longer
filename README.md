# Number type bigger than double

This library is designed to be able to store numbers larger than a double and for the sole purpose of incremental games. While tools like BreakInfinity exist, I would much rather have an implementation that isn't tied to any features of unity.

The project runs with C#14 and above (Not tested)

The current implementation is very bad and I might even drop the project if I don't feel like continuing with it or I don't need it.
There are better repositories out there like [BreakInfinity](https://github.com/razenpok/BreakInfinity.cs/tree/master)
